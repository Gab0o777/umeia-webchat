Umeia widget — test page

This page embeds the widget pointed at a local umeiacore instance (http://localhost:8000) for tenant infoumeiaio. Run uvicorn main:app --reload in umeiacore/ first, then open this file directly in a browser (or serve it with python3 -m http.server 5500 to match the origin already allow-listed in tenant_configs/infoumeiaio.json).

Click the bubble in the bottom-right corner to open the chat.
