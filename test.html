Umeia widget — demo page

This page embeds the widget pointed at the real production umeiacore (https://umeia.space) for tenant infoumeiaio, served from this same domain (webchat.umeia.io) — it's what loads when a browser hits this URL directly, since the domain's root has no page of its own (this project only serves widget.js as a static asset).

To point at a local umeiacore instead (for engine changes, not widget-only changes): run uvicorn main:app --reload in umeiacore/, then change data-api-base below to http://localhost:8000 and open this file directly (or serve it with python3 -m http.server 5500 to match the origin already allow-listed in tenant_configs/infoumeiaio.json).

Click the bubble in the bottom-right corner to open the chat.
